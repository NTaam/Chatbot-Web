This is a project about a chatbot integrated with a website.

This project will integrate a chatbot that can communicate with customers. The answers will be pre-prepared, depending on the questions from users, the corresponding answers will be provided.

# Fashion-Shop
To run the chatbot product on the web, please run the code "python -m uvicorn demoAPI:app --reload"
